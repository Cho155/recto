# 内存测量 · 2026-11-02 · 阶段 3b · 测试虚拟机

环境同 [`../2026-11-02-vm-phase3/`](../2026-11-02-vm-phase3/README.md)，另有两个托盘应用在运行：fcitx5（两种键盘布局）和 nm-applet。外壳用 cairo 渲染器。

| 时刻 | 外壳 PSS | 文件 |
| --- | --- | --- |
| 重启外壳后空闲 60 秒（托盘服务、输入法指示、麦克风监听都在运行） | 18.9 MiB | `idle.json` |
| 托盘面板和 nm-applet 菜单打开 | 20.0 MiB | `menu-open.json` |
| 关闭 30 秒后 | 19.4 MiB（空闲的 103%） | `after.json` |

另外，“Mic in use” 依靠一个 `pactl subscribe` 子进程：**2.1 MiB PSS**（RSS 4.9 MiB）。

结论：
- 托盘和输入法指示几乎不增加空闲内存：面板和菜单只在打开时存在，关闭即释放。
- 麦克风提示的全部代价就是这 2.1 MiB 的子进程。另一个方案是把 PipeWire 链接进外壳，但那要在编译时依赖 bindgen 和 clang，代码也更多，所以没有采用（决策 D37）。
