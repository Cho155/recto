# 体验改进想法（2026-11-09）

作者让助手“认真想想还能怎么提升体验”，只记想法，不写代码。这里的条目都**还没定、没做**；作者挑中的再按惯例写进 DECISIONS、在测试机里做。

怎么想出来的：重读了 VISION、DESIGN-LANGUAGE、INTERACTION、DECISIONS 和截图；只读看了作者账户里装了哪些应用、Recto 装的是哪一版、当前模式（没有运行、没有改动任何东西）；再站在一个和作者审美相同、每天用 X230 的人的角度，问三件事：哪里还在硬、哪里还有接缝、哪里可以更像一本书。

每条写：是什么 → 为什么 → 代价或风险。优先级：★★★ 先做，★★ 值得做，★ 可选。

## 〇、先说两件看到的事

- **作者账户里的 Recto 还是 11 月 5 日的版本。** `~/.local/share/recto/shared/niri/config.kdl` 里还有 `timeout 600 … recto-theme lock`，也就是说 D110（去掉空闲锁屏）还没装上，空闲 10 分钟仍会锁屏。要作者运行一次 `./install.sh` 并重新登录。（这也说明“改完要记得重装”本身就是一处摩擦，见一·10。）
- **作者从 11 月 6 日上午起固定用 Ink**（`mode` 文件是 `ink`，不是 Auto）。所以 Ink 才是每天真正看到的样子，下面跟外观有关的想法都先按 Ink 考虑。为什么白天也不用 Paper，值得问一句（见四）。

## 一、日常使用里的摩擦（最值得先做）

1. ★★★ **关机、重启、休眠、注销没有入口。** 现在只有 `Super+Shift+E` 注销，关机得开终端敲 `poweroff`。
   - 做法：搜索里加 “Shut down” “Restart” “Suspend” “Log out” 四个动作；选中后这一行原地变成 “Shut down now · Cancel” 再确认一次，不弹对话框。今日页最底下也可以放一行（见三·6 的“版权页”）。
   - 代价：很小，走 logind 的 D-Bus 或 `systemctl`。

2. ★★★ **搜索索引里有很多杂项。** 作者机器上搜索能列出 31 项，其中约三分之一是不该出现的：Foot Server、Foot Client、Qt V4L2 两项、xgps 两项、lstopo、Keyboard layout viewer、Fcitx 5 Migration Wizard、NetworkManager Dmenu；还有两个 Noctalia 入口——在 Recto 里点开会再起一条状态栏。名字的大小写也不统一（“wechat”“WemeetApp”“btop++”“kitty”）。一本书的索引不会这样排。
   - 做法：
     - 默认隐藏一小份已知的“管道”入口（foot 的服务端和客户端、Xwayland、各种测试工具）；
     - “Foot” 改叫 “Terminal”，打开的是 `footclient`；
     - 一张常见应用的正名表（wechat → WeChat，WemeetApp → Tencent Meeting）；
     - 令牌或 `local` 配置里给用户一份自己的隐藏列表。
   - 再加上按使用次数排序：空白搜索时，最常开的几个（大概是 Firefox、Code、WeChat、终端）排在最前，其次才是字母序。次数只存一个小文件。
   - 代价：小。顺带把 D45（读 Keywords）一起做了，“browser” 能找到 Firefox。

3. ★★ **计算和进制换算。** 作者常做逆向和 pwn，`0x41` 是几、`0x7ffd…` 减一个偏移，这类事现在要开 Python。
   - 做法：搜索框里输入以 `=` 开头或像数字表达式的内容，第一行直接给结果，排成一行：“65 · 0x41 · 0b0100 0001 · ‘A’”。Enter 复制。
   - 只做整数、十六进制、位运算和四则，不做单位换算，免得变成另一个程序。

4. ★★ **打开的窗口也进索引（像书的目录）。** niri 的横排一长，找窗口只能靠总览一张张看。
   - 做法：搜索结果里加 “Window” 一类，按窗口标题匹配（“Firefox — Arch Wiki”），Enter 跳过去（`niri msg action focus-window --id`）。索引是应用，目录是窗口，一个入口。

5. ★★ **剪贴板历史（像摘抄本，commonplace book）。** 写代码、做题时来回复制很多，现在只有最后一条。
   - 做法：外壳记最近 20 条文字，只在内存里（和通知历史一样，D31），跳过密码管理器标了 `x-kde-passwordManagerHint` 的内容；搜索里加前缀或单独一个键打开，选中即放回剪贴板。
   - 代价：要接 niri 支持的 data-control 协议，内存要量；按键要找一个空位（`Super+V` 已被浮动窗口占了）。

6. ★★★ **按应用定列宽和浮动（为 1366×768 和作者常用的应用）。**
   - 1366 宽的屏上，默认半宽是 670 px 左右，Firefox 和 VS Code 会被挤进窄版式。浏览器和编辑器默认 2/3 宽，聊天和终端保持 1/2。
   - 微信、腾讯会议的小窗口（图片查看、会议工具条、共享屏幕时的小条）、文件选择框、pavucontrol、fcitx5 设置这类，默认浮动。
   - 代价：要准确的 app-id。作者在用的时候运行一次 `niri msg windows`，把输出发给助手就行；规则写在模板里，对所有用户都有用。

7. ★★ **托盘项“需要注意”时，栏上要看得出来。** 微信来消息时它的托盘图标会闪（SNI 的 `Status = NeedsAttention`）。Recto 的托盘只列文字、默认折叠，这个信号现在被吞掉了；如果微信在 Linux 上不发系统通知，消息就可能漏看。
   - 做法：有托盘项需要注意时，托盘箭头旁出现一个陶土色的小标记（和未读通知同一种写法，见三·2）；托盘列表里那一项用正文色加斜体 “New”。托盘里的名字也走第 2 条的正名表。
   - 先确认：微信在作者机器上发不发系统通知。

8. ★★ **共享屏幕时自动收起通知。** 上网课用腾讯会议共享屏幕时，微信消息作为通知弹在屏幕右上，所有人都看得到。
   - 做法：检测到正在录屏或共享时，自动进入专注模式（紧急的照常弹），状态栏出现一句 “Sharing screen”（和 “Mic in use” 同一个位置）。
   - 先查：niri 的 IPC 报不报告录屏状态；不报的话，从 PipeWire 里看有没有 niri 产生的视频流。

9. ★★ **电量数字点开是省电模式。** 作者装了 power-profiles-daemon，X230 用电池时有用。
   - 做法：点电量数字，在下面打开一张小纸条：一句电量（“82%, about 5 h left”）和 “Power saver · Balanced · Performance” 三个斜体词，当前的带陶土色下划线（和 “Paper · Ink · Auto” 同一个写法）。没有这个服务就不能点。

10. ★★★ **更新提醒。** 现在的循环是助手提交、作者记得重装；这次就漏了一轮（见〇）。
    - 做法：安装时把提交号写进数据目录；今日页底部在仓库比已安装的新时，安静地写一句 “Recto has changes since you installed it.”，搜索里有 “Install Recto update” 动作，开一个终端运行 `./install.sh`（仍然是作者自己运行，符合 D96）。
    - 代价：小。只比较本地仓库，不联网。

11. ★★ **左上角的热角。** niri 默认在左上角有一个热角，碰到就开总览；而 Recto 的工作区罗马数字正好在左上角。测试机为了点击准确关掉了热角（D39），所以这件事**从来没在 Recto 里试过**。鼠标甩到左上角去点 “I”，很可能误开总览。
    - 先问作者有没有遇到；遇到就默认关掉，总览留给 `Super+O` 和触摸板手势。

## 二、最常看的几块还没换上 Recto（接缝）

桌面的框已经是一本书了，但作者大部分时间看的是框里的东西：终端、VS Code、Firefox、微信。这里是“装上就好看”和“用起来处处一致”之间的差距。

1. ★★★ **终端提示符。** 作者看得最多的一行字是 Arch 默认的 `[Tibo@archlinux ~]$`。DESIGN-LANGUAGE 早就写了“提示符只用一个陶土色箭头，路径用次要色”，但 Recto 没有提供。
   - 做法：Recto 提供 `…/shared/shell/prompt.bash`，作者自己在 `~/.bashrc` 里加一行 `source`（Recto 不改作者的配置，D96）。样子：路径用次要色，git 分支用斜体次要色，一个陶土色的 `›`；上一条命令失败时，箭头前多一个砖红的退出码。只有一行，不放时间、用户名、主机名（SSH 进来时才显示主机名）。
   - 顺带一份 `dircolors`：目录用正文色加粗，可执行文件用陶土色，链接用斜体，其他用正文色，不要满屏的蓝绿。

2. ★★★ **VS Code 的 Recto 主题。** 作者装了 VS Code，默认的 Dark Modern 是冷蓝灰配亮蓝状态栏，是桌面上最大的一块冷色。
   - 做法：从令牌生成 “Recto Paper” 和 “Recto Ink” 两套颜色主题，沿用 D75 编辑器配色的思路：大部分代码是正文色，关键字粗体，注释斜体，字符串略淡，只有极少数地方用陶土色；界面用 base、raised、line 三层纸色，状态栏不是一整条彩色。编辑器字体 Monaspace Xenon。用 `window.autoDetectColorScheme` 跟着 Paper／Ink 自动换。
   - 打成 `.vsix`，由作者自己 `code --install-extension` 装、自己选主题，Recto 不改 VS Code 的设置文件。这一项对开源用户也有吸引力。

3. ★★ **Firefox。** 先看再做：Firefox 在 Linux 上的“系统主题”会读 GTK 颜色，可能已经有几分 Recto 的样子。请作者截一张图再决定。
   - 确定值得做的一件：阅读模式（Reader View）。新版 Firefox 的阅读模式可以自定字体和颜色；设成 Source Serif 4 加 Recto 的纸色和墨色，长文章就是一页书。Recto 提供一小段 `user.js`，作者自己放进配置目录。
   - 不默认做 `userChrome.css`：要改 Firefox 的配置开关，每次 Firefox 大版本更新都可能坏。

4. ★ **终端里的程序。** 用终端 16 色的程序会自动跟着 Recto 变色，几乎不用做事：
   - btop 在设置里选内置的 “TTY” 主题，就会用 Recto 的终端色，并且跟着 Paper／Ink 一起换；
   - Claude Code 的 `/theme` 里如果有 “ANSI colors only” 的深色和浅色两项，选上就会用 Recto 的终端色；
   - pwndbg、radare2 大多用 16 色，已经跟着走。
   - 这些写进 README 的“常用应用”一节就够了，不需要 Recto 改别人的配置。

5. ★ **登录界面。** 开机后第一眼看到的是 tuigreet 的默认配色，是“封面”上的一道接缝。
   - 轻做法：tuigreet 的 `--theme` 可以按 16 色设配色，再加 `--time` 和一句问候；把控制台的 16 色设成 Ink 的终端色，控制台字体用已装的 Terminus。
   - 重做法（以后）：换成 GTK 的 ReGreet，登录页就是扉页，带图版。
   - 两种都要改 `/etc` 下的系统配置、要 sudo，只能做成 `install.sh` 之外的可选步骤，由作者自己运行。GRUB 主题同理，风险更大，排最后。

6. ★ **单色表情。** 微信通知里的彩色 emoji 是 Recto 页面上唯一的彩色块。外壳自己的界面（通知、今日页）可以让 emoji 落到单色的 Noto Emoji（OFL）上，跟正文一样“用墨印出来”。只影响 Recto 的外壳，不影响微信和浏览器本身。需要下载字体（约 2 MB），先问。

## 三、让它更像一本书（点缀，要克制）

D49 说多出来的预算要花在质感上而不是加元素。下面每一条都只用排印的手段，不加控件。

1. ★★★ **白天一张画，夜里一张画。** 现在 Ink 下桌面上是压暗的 Hammershøi，阳光照在地板上的那间屋子，在暗桌面上是整个屏幕最亮的一块灰（见 `2026-11-03-vm-recto-default-ink.png`）。
   - 做法：Paper 和 Ink 各自有一张图版。Paper 用现在这张白天的室内；Ink 用一张本来就暗的画：烛光或月光，暗处里只有一小团暖光，正好就是 Ink 的颜色。用 Auto 的人，傍晚七点桌面会从阳光换成烛光；锁屏扉页跟着换。
   - 候选方向（都要按 D93 从 CC0 博物馆库里逐张核对授权）：Rijksmuseum 收藏里 Schalcken、Dou 的烛光画；Whistler 的夜曲；Dahl 或 Friedrich 的月光风景；Hammershøi 自己更暗的室内。
   - 代价：令牌里图版分主题（`theme.ink.plate`），生成脚本已经支持；挑画要下载候选图，先问作者，做一页候选页给作者挑（和 D93 一样）。
   - 以后再说：十二个月各一张，像一本艺术日历。

2. ★★ **未读通知用脚注号，不用圆点。** 状态栏日期左边的陶土圆点换成一个上标的旧体数字 “²”，像正文里等着读的脚注；打开今日页（读脚注）就消失。数字比圆点多说了“有几条”，又是纯排印的写法。托盘的“需要注意”（一·7）用同一个记号。

3. ★★ **页眉的书眉（running head）。** 书的每一页顶上都有书眉：这一章的名字。状态栏中间现在是空的（D9），可以用斜体次要色、小字号排当前窗口的标题，过长就截断。
   - 好处：没有标题栏的终端也看得出是哪一个；很像书。
   - 风险：浏览器标题和终端标题变化频繁，页眉会“动”起来。只适合在测试机里做出来、截图给作者看，由作者决定要不要。可以只排应用名加一个短标题。

4. ★★ **今日页的历书行。** 日期下面加一行小字，像老历书和时祷书的日历页：“Day 313 · Week 46 · Sunrise 6:24 · Sunset 17:03 · First quarter”，月相用一个细线画的小月亮。
   - 日出日落不需要位置权限：tzdata 的 `zone1970.tab` 给每个时区一个城市坐标（Asia/Shanghai 是上海），够准；令牌里可以改坐标。
   - 同一个计算可以让 Auto 模式按日落切 Ink（见 7）。

5. ★ **题词（epigraph）。** 今日页日期下面每天一句公有领域的引文，斜体，作者名用小型大写：Montaigne、Marcus Aurelius、Thoreau、Emerson……像一章开头的题词。
   - 很看口味，可能显得做作，默认关；要做就认真挑一份三百多句的清单，不要网上的“励志语录”。

6. ★★ **版权页（colophon）。** 今日页最底下一行小字，像书末的版权页：“Set in Source Serif 4 · Recto 0.9 (66ecfba)”，右边是 “Suspend · Restart · Shut down” 三个斜体词（一·1），有更新时说一句（一·10）。三件事放在一个书里本来就有的位置，不新开面板。

7. ★ **Auto 按日出日落。** 现在 Auto 是固定的 07:00／19:00（D43，当时因为“要位置信息”没做日落）。用 4 里的时区坐标，冬天五点天黑就换 Ink，夏天八点才换。作者现在用固定 Ink，这条主要是给开源用户的。

8. ★ **灯下（夜里屏幕偏暖）。** 夜里把整个屏幕的色温调低一点，像在灯下看书。和 Ink 是两回事：Ink 换的是纸，这个换的是光。
   - 风险：会把画的颜色一起染黄，只能调得很轻（5000 K 左右）；多一个常驻进程（约 1–2 MiB）。可选，默认关。

## 四、要作者的真机才能定的事

1. **真机截图。** 所有外观都是在测试机的 1440×900 上调的，作者的屏幕是 1366×768、约 125 PPI 的 TN 面板。衬线体的小字号在这种屏上可能发虚或发细，尤其 Ink 下浅色字。
   - 请作者截三张（`Ctrl+Print` 截整屏，存在 `~/Pictures/Screenshots/`）：今日页、搜索、一个终端加一条通知。截图是像素级的，助手可以直接看出字的渲染，再决定要不要调 fontconfig 的 hinting 或次像素渲染。
   - 同时把测试机的分辨率改成 1366×768，以后的截图更接近作者看到的样子。
2. **为什么固定用 Ink？** 如果是 Paper 在这块屏上还是太亮，可以再试一档更暗的纸（像电子书的“羊皮纸”档）；如果只是喜欢暗色，就把精力都放在 Ink 上。
3. **小红点（TrackPoint）手感**：Recto 只配了触摸板，X230 的小红点要不要调速度。
4. **微信发不发系统通知**：决定一·7 和三·6 的做法。
5. **左上角热角有没有误触过**（一·11）。

## 五、考虑过、不建议做

- **声音**（翻页声、纸张声）：第一天觉得有趣，第三天就想关；大多数桌面的提示音最后都被关掉。
- **翻页动画**（切工作区像翻书）：太像道具，和“只移动几个像素、不弹跳”（动效原则）相反。现在的弹簧已经对了。
- **换一整套图标主题或花哨的光标**：图标多的地方（Nautilus）本来就不是 Recto 的画面；换主题的收益小、包大。
- **毛玻璃**：D78 已经说清楚了。
- **Recto 自己的快捷键页、页眉上的搜索入口**：作者已经不要（D103）。一次性的欢迎纸条（“Super+Space searches · Super+A opens Today · Super+Shift+/ lists keys”）对新用户有用，但只在第一次安装后出现一次，作者不会再看到。
- **默认改 Firefox 的 `userChrome.css`**：见二·3。
