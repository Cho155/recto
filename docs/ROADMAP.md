# 路线图

最终成品的样子还说不清楚，所以先让它**能被看见**，再逐步落地。每个阶段都有明确的完成标准。

## 阶段 0 · 样张（看得见的设计）

用 HTML 做一组静态样张，在浏览器里对比，不写任何桌面代码。

- 配色：纸和墨两套，放在真实尺寸的状态栏、面板、终端上看。
- 字体：衬线、无衬线、等宽三款的搭配。
- 状态栏：三到四种布局方案，包括“卷轴缩略”。
- 终端：半透明纸色和墨色终端在不同壁纸上的可读性。

**完成标准**：配色、字体和状态栏方案定稿，写回 `design/tokens.toml` 和决策记录。

**进度**：v0 已完成（2026-11-02），设计由助手决定（作者授权）。

## 阶段 1 · 主题包（不写外壳也能日用）

只靠配置和主题，让现有工具先变成留白的样子。

- 令牌生成脚本：输出 niri、foot、kitty、alacritty、fuzzel、mako、GTK、Qt 的配置。
- 字体安装说明、等高线壁纸生成器。
- 安装方式：在独立目录生成，由用户自己决定是否链接到 `~/.config`，不直接覆盖现有配置。

**完成标准**：在虚拟机里的干净 niri 环境中装上后，截图与样张一致；记录一次整个会话的内存基线。

**进度**（2026-11-02）：已完成，并在测试虚拟机中验证（锁屏除外），结果见 [THEMES.md](THEMES.md)。Qt 主题、swayidle 尚未做。

## 阶段 2 · 最小外壳与测量

用 Rust + GTK4 做一个最小外壳（时钟、工作区、一张可开关的面板），在虚拟机中按[架构文档](ARCHITECTURE.md)的方法测量，并比较 GTK4 的几种渲染器。

**完成标准**：有测量记录；满足预算，或按决策 D3 的条件重新评估技术栈。

**进度**（2026-11-02）：已完成。外壳空闲 18.9 MiB、打开今日页 20.0 MiB、整个桌面 133.5 MiB（PSS），全部在预算内，技术栈保持 Rust + GTK4。测量过程中决定外壳默认使用 cairo 渲染器（D26）。见 [`reports/memory/2026-11-02-vm/`](../reports/memory/2026-11-02-vm/README.md)。

## 阶段 3 · 外壳第一版

- 状态栏：工作区与卷轴缩略、时钟、按需出现的状态提示、托盘。
- 通知：通知服务，替代 mako。
- OSD：音量和亮度提示。

**完成标准**：在虚拟机中稳定运行；外壳满足空闲内存预算。是否日用由作者决定。

**进度**（2026-11-02）：拆成 3a 和 3b，规格见 [INTERACTION.md](INTERACTION.md)。
- 3a 已完成并在虚拟机中验证：通知服务、音量和亮度提示、按需出现的状态提示、专注模式、未读圆点。外壳空闲内存仍为 18.4 MiB。
- 3b 已完成并在虚拟机中验证：托盘（含 dbusmenu 菜单）、输入法指示（fcitx5）、“Mic in use”。

阶段 3 完成。

## 阶段 4 · 外壳完整版

- 搜索：启动器，替代 fuzzel。
- 今日页。
- 锁屏，替代 swaylock。
- 纸／墨按时间自动切换。

**进度**（2026-11-02）：
- 已完成并在虚拟机中验证：
  - 搜索；
  - 纸／墨按时间自动切换；
  - 空闲锁屏（swayidle）；
  - 授权弹窗（polkit-gnome）。
- 锁屏决定继续用 swaylock（D41）。
- 待做：今日页的日程（先测 Evolution Data Server 的内存代价）。规格与验证结果见 [INTERACTION.md](INTERACTION.md)。

**进度**（2026-11-03）：
- 审美打磨与古典化（D48–D85）：动效、阴影、光学尺寸；书页风格的状态栏、整页今日页、页边纸条、索引式搜索；图版壁纸与扉页锁屏；
- 今日页的“正在播放”（MPRIS）；
- Qt 6 主题（qt6ct）、文本编辑器配色、GTK 应用的衬线标题。
