# 设计语言

数值的唯一来源是 [design/tokens.toml](../design/tokens.toml)，本文只说明用途和理由。数值已画进[样张](../design/specimen/)，实现后在虚拟机里看过实物再微调。对比度一律按 WCAG 2.x 公式计算。

## 古典，而不是 Windows

作者 2026-11-03 定下的方向（D63）：界面借用书页和印刷的语汇，不用浮动卡片界面的语汇。这里的书页指西方的书籍和出版物（D91）：排印、抄本、版画、油画，不是中式的水墨和卷轴。落到细节上：

| 用 | 不用 |
| --- | --- |
| 版心与页边空白、1 px 细线 | 大圆角卡片、大阴影 |
| 衬线正文、小型大写的标签、旧体数字 | 粗体标题、全大写加粗的按钮 |
| 可以点的文字（斜体、下划线） | 胶囊形按钮、分段控件的方框 |
| 陶土色的红字标注：一道细线、一行小型大写的动作 | 彩色徽标、彩色图标 |
| 纸条“放下”：原地淡入，几乎不动 | 从屏幕边缘滑入的横幅 |
| 整页（今日页） | 居中浮着的对话框 |
| 线条画加一行图版说明 | 渐变、毛玻璃、霓虹 |

### 用色规则

1. 一屏之内陶土色出现得越少越好：焦点窗口边框、当前工作区标记、需要注意的提示点。
   它的角色是**红字**（rubric，D67），像西方抄本和早期印刷书里用红墨印的标题和提示：紧急通知左边的一道细线、通知里可以执行的动作（小型大写）、选中项下的一条下划线。
2. 颜色不单独表达含义，必须同时有文字或形状。
3. 陶土色只表示“这里需要注意”，不表示出错。出错、删除这类危险操作使用 `danger`（暖砖红）。这样“注意”和“危险”能区分开，而砖红仍属于同一组暖色。
4. 陶土色作底色时，上面的文字用深色（`accent_fg`），因为纸色字在陶土色上只有 2.96 : 1。
5. 纸上的终端光标用深陶土（`#B4532E`）：原版陶土色在纸上只有 2.94 : 1，低于界面元素要求的 3 : 1。

## 终端配色

16 色都在终端的实际背景上测量对比度（纸 90% 不透明叠在壁纸上约为 `#F9F8F4`，墨 86% 约为 `#1E1D1C`）。

- 纸：所有彩色 ≥ 4.5 : 1。`bright_black`（4.16）和 `bright_white`（3.34）刻意做暗，用于命令补全提示、注释这类弱化文字。
- Ink：彩色 5.37–9.09 : 1；`black`（1.46）只作底色用，不作文字。
- 色相全部偏暖、降低饱和度：红是砖红，黄是赭石，蓝偏灰。整体像印在纸上的颜色，而不是屏幕上的霓虹色。
- 提示符只用一个陶土色箭头，路径用次要色（见样张）。

## 字体

Anthropic 的品牌字体是商业授权，不能随项目分发。全部采用开源（OFL）字体（决策 D7）：

| 角色 | 字体 | 用在哪里 | 应用内字号 |
| --- | --- | --- | --- |
| 衬线 | Source Serif 4 | 外壳里所有要读的文字：状态栏、今日页、通知、搜索、托盘、音量提示 | 外壳内按像素阶梯 |
| 无衬线 | Inter | GTK 应用的界面（经 gsettings）、后备启动器 fuzzel | 界面 10.5 pt，启动器 12 pt |
| 等宽（终端） | Monaspace Xenon（D98） | 终端、代码 | 10 pt，行高 14.25 pt |

Monaspace Xenon 是带衬线的等宽体，有打字机稿的味道，笔画结实，低分辨率屏幕上也清楚；有真正的斜体和粗体。字面大，10 pt 读起来和 IBM Plex Mono 10.5 pt 一样大；行距放宽到 1.4 倍左右，像书页而不是表格。

中文、日文、韩文（D99）：上面三款字体都没有汉字，各自后面接一款同类的 CJK 字体，衬线接衬线、等宽接等宽：Source Serif 4 → Noto Serif CJK SC（宋体），Inter → Noto Sans CJK SC（黑体），Monaspace Xenon → Noto Sans Mono CJK SC。用 SC（简体中文的字形和标点位置）；令牌是 `font.cjk`。终端里汉字用 11.5 pt，正好填满两个字符格，不留缝。规则写在 fontconfig 里（`templates/fontconfig/recto.conf`），所以外壳、GTK、Qt、终端、浏览器都一样。

GNOME 的“文档字体”（给要读的文字用）设为 Source Serif 4 11 pt；文本编辑器的正文区用 `recto` 配色（D75），像印刷页：大部分是正文色，结构用粗体，注释用斜体，Markdown 的列表符号用陶土色。

- 2026-11-03 起外壳以衬线体为主（D64），像一本书：正文用正体，补充说明用斜体，标签用小型大写。
- 小型大写：`font-feature-settings: "c2sc", "smcp", "onum"`，字距 1–1.5 px，用于页眉式的标签（“TUESDAY · 2026”“RIGHT NOW”“BATTERY · NOW”）、工作区名和通知里的动作。
- 旧体数字（`onum`）：数字有高有低，和小写字母一起排时不突兀；时钟和百分比用等宽旧体（`tnum onum`），不会跳动。
- 没有名字的工作区用罗马数字（D65）。
- 光学尺寸（D56）：Source Serif 4 为不同字号分别设计了字形。40 px 以上（今日页的日期）用 Display，笔画更细、更挺；16 px 以下（状态栏的时钟和工作区名）用 SmText，更扎实。两者都以普通 Source Serif 4 兜底，令牌是 `font.serif_display` 和 `font.serif_small`。
- 外壳字号阶梯：12 / 13 / 15 / 18 / 24 / 40（逻辑像素）。fontconfig 和 Pango 用点数，1 pt ≈ 1.33 px。

## 形状与空间

- 窗口圆角 6，面板圆角 3，小控件圆角 2（D66）：印刷品的角是方的，小圆角只为让边缘柔和。
- 分隔用 1 px 细线，不用粗边框。
- 焦点窗口 1 px 陶土色细线；其他窗口不画边框，只靠阴影。外壳里用键盘移动时，按钮的焦点也是同样的 1 px 陶土细线（D80）。
- 阴影分三档（D55），表示离桌面的高度：
  - 静置的窗口：柔和度 20，向下偏移 3，纸上 8% 暖黑色，墨上 30% 黑色；
  - 抬起（当前窗口）：柔和度 40，偏移 10，纸上 12%，墨上 45%；
  - 小卡片（通知、音量提示、搜索、菜单）：柔和度 18，偏移 6（D72）。
- 外壳的纸条用两层阴影：一道贴近的接触线（`shadow_near`）加一圈柔和的外扩。阴影由 CSS 画，所以会跟着纸条一起移动。
- 今日页是整页（D69）：一页不透明的纸盖住桌面，没有边框和阴影；只在打开和关闭的淡入淡出里能看到下面的桌面。
- 窗口间距 14。终端内边距 18。状态栏高 32，左右内边距 16。
- 不把每个元素都包成胶囊。优先空白和对齐基线。

## 透明与模糊

- 外壳面板、通知、搜索：不透明。
- 终端：纸 90%、墨 86% 不透明。
- 焦点框不画在窗口背后（niri `draw-border-with-background false`），否则获得焦点的半透明终端会透出陶土色。
- 背景模糊：niri 26.04 实现了 `ext-background-effect-v1`，foot 可以开启。Recto**不用**（`terminal.blur = false`，D78）：
  - 模糊加噪点是 Windows 的“亚克力／云母”材质，和古典方向相反；
  - 半透明而不模糊的纸色终端像一张硫酸纸，透明本身已经足够有质感；
  - 关闭时还能省下显存。

## 动效

原则：东西从它来的地方来，回到它来的地方去；只移动几个像素，不弹跳、不过冲。

- 打开、关闭：减速曲线（ease-out-cubic），打开 240 ms，关闭 160 ms。悬停和按下的颜色过渡 120 ms。
- 能被手势驱动的移动（滚动列、切换工作区、移动窗口、总览）：临界阻尼弹簧（阻尼比 1.0，刚度 800）。弹簧能接住手指松开时的速度，又**不回弹、不过冲**。刚度比 niri 默认的 1000 略低，动作更从容。
- 外壳的面板（D51，后按 D68 收小）：
  - 今日页：纸页一下子铺满（像翻过一页，D87），文字淡入并从上方落下 6 px；
  - 搜索：从状态栏的方向落下 6 px，同时淡入；
  - 音量提示：从屏幕底部升起 6 px；
  - 通知：纸条原地放下，只向左移动 6 px；其他纸条平滑让位；离开时停在原地淡出，下面的纸条补上（D53）；
  - 关闭时原路退回。只用透明度和平移，不缩放，文字不发虚。
- 窗口（D54）：开窗像把一张纸放到桌上，从大 2% 落定并淡入；关窗时抬起、淡出。阴影包含在窗口画面里，一起移动。
- 减少动态效果：关闭 GTK 的 `enable-animations`（`gsettings set org.gnome.desktop.interface enable-animations false`）后，外壳的面板不再有任何动画，关闭时立即消失。令牌 `motion.travel` 设为 0 则只保留淡入淡出。niri 的动画由它自己的 `animations { off }` 控制。

## 图标与插画

- 外壳里的小图标（关闭、下拉、更多）由外壳用 cairo 自绘，线宽统一为 `shape.icon_stroke`（1.5 px），圆头圆角，颜色跟随文字（D58）。不依赖系统的图标主题。
- 需要更多图标时，用现成的细线图标库：Lucide，或 Phosphor 的 Light 版，线宽同上。
- 不使用 Nerd Font 图标作为界面主图标。搜索和通知默认不显示应用图标：彩色图标会打破画面，而文字已经足够辨认。
- 插画用“图版”的方式（见下一节）：作者挑线条画，Recto 负责上色和排版。

## 壁纸

### 图版（D70）

作者提供线稿时（`wallpaper.plate`），壁纸是一页印着插图的纸：
- 线稿是 SVG（要有 `viewBox`）或 PNG，深色线，浅色或透明底；放在 `design/plates/`，说明见那里的 README。
- 生成时先铺白底，再把深浅换算成油墨量，用主题的 `plate_line` 上色：纸上是浅褐灰的线，墨上是暗灰的线。同一张线稿两套都合适。
- 位置 `plate_place`（left、center、right），最多占屏幕宽度的 `plate_width`、高度的 62%，略低于正中。
- `plate_caption` 排在图下，斜体、次要色，与图的边对齐：“Fig. 1 — 标题, after 作者”。
- 纸纹叠在线条之上，像印在纸上。

### 等高线

没有线稿时，用程序生成的等高线（决策 D10）：

- 在屏幕下半部分画 12 条细线，每条由三组缓慢的正弦波叠加而成。
- 相邻线条共用波形，只有很小的相位漂移，所以彼此顺着走、不交叉。
- 线条向右缓缓抬升，越往下越平。
- 线色只比底色深一点，属于装饰。
- 按每块屏幕的实际像素尺寸生成，线宽为 1 个逻辑像素。
- 随机种子固定，所以每次生成的结果都一样。
- 纸纹（D57）：整张壁纸叠一层极细的分形噪点，颜色是正文色，最浓处 4%（`wallpaper.grain`）。正常大小下只觉得纸面温润，放大才看得见斑点。生成一次后缓存，运行时没有代价。面板不加纹理。

### 锁屏：扉页（D71）

锁屏用同一张壁纸，在左上方排出当天的星期（斜体、次要色）和日期（Display 字体），像一本书的扉页。每天生成一次，切换主题和登录时就提前生成；输入密码时才出现细圆环。

## 文案

界面默认英文（作者决定）。

- 用平实的词：Notifications、Search、Today。内部设计隐喻（边注、索引、横排书页）不出现在界面上。
- 句首大写（sentence case），用完整的短句：“Connected · Home Wi‑Fi”“Battery at 15%, about 25 minutes left.”
- 不用全大写、不用感叹号、不用技术缩写代替日常说法。
- 所有字符串集中管理，为翻译预留接口。
