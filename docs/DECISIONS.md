# 决策记录

## 2026-11-02 · 立项

作者的要求：

- 审美借鉴 Anthropic 的简约风格，包括配色；一改普遍的极客风格；保留透明终端这类提升审美的设计。
- 图案使用线条画风格，不是简笔画；插画作为保留项。
- 可以借鉴 niri、Noctalia 等现有工具，也可以不用、换用其他工具或自行设计。
- 内存占用尽量低。
- 是开源项目，不只为作者当前的笔记本设计。
- 最终成品的样子在完成前难以描述，需要边做边看。

## 2026-11-02 · 作者的决定

- 本项目与作者此前的其他项目无关，不引用、不复用。
- **不允许在本机进行任何测试**（安装、构建、运行、修改本机配置都不做）。唯一允许测试的地方是作者提供的虚拟机；本轮不测试。虚拟机的登录信息只由作者在对话中提供，不写进仓库或任何记录。
- 设计上的选择交给助手决定。
- **界面语言默认英文**。其他语言的渲染由作者单独支持。

## 2026-11-03 · 作者：内存够了，转向审美

作者的判断：常见的极客桌面动辄占用 2 GB，留白现在约 150 MB，已经完全符合“简约”。整个会话只要在几百 MB 以内都可以接受。内存这么低，说明在视觉体验上还有很大的改进空间。下一阶段的重点是**审美优化**。

| 编号 | 决定 | 理由 |
| --- | --- | --- |
| D48 | 内存预算放宽：整个会话空闲 ≤ 400 MiB，外壳空闲 ≤ 100 MiB；仍然每次测量、留记录 | 作者确认几百 MB 以内都可以接受；保留明确的上限，免得不知不觉越涨越多 |
| D49 | 多出来的预算优先花在动效、材质和排版上，而不是往界面里加更多元素 | “安静”仍是第一原则：看起来更讲究，而不是更热闹 |

## 2026-11-03 · 审美优化：动效、材质、排版

| 编号 | 决定 | 理由 |
| --- | --- | --- |
| D50 | 外壳继续用 cairo 渲染器，动画也用它画 | 原计划为了动效换 GL（约多 24 MiB）。虚拟机实测，最大的今日页每帧绘制中位数 9.7 ms，帧间隔稳定在 13.3 ms（75 Hz 跑满）；GL 经 virgl 反而要 23 ms。高分屏像素是 4 倍，真机上要重测，掉帧时再换 GL（`GSK_RENDERER=gl` 即可，见 `reports/motion/`） |
| D51 | 面板的动效写成 CSS 关键帧：今日页和搜索从上方落下 8 px，音量提示从下方升起，通知从屏幕边缘滑入 24 px；离开时原路退回，更快 | 同一套令牌（`motion.travel`、`travel_side`、时长、缓动）生成全部关键帧；只用透明度和平移，不缩放，文字不会发虚 |
| D52 | 关闭面板时先交出键盘、停止接收点击，播完离开动画再销毁窗口（`motion.rs`） | 用户按 Esc 或从搜索打开应用时，键盘要立刻还给后面的窗口；但窗口本身要留到最后一帧，否则只能瞬间消失 |
| D53 | 每张通知卡片放在一个伸缩容器（GtkRevealer，SlideUp）里 | 新卡片插入、旧卡片离开时，其他卡片平滑让位，而不是跳动；SlideUp 让离开的卡片停在原地淡出，而不是被往上推走 |
| D54 | 窗口开合用 niri 26.04 的自定义着色器：开窗时从大 2% 落定并淡入，关窗时抬起淡出（`motion.window_lift`） | 像把一张纸放到桌上；niri 默认的开窗是从一半大小弹出，太活泼。着色器在合成器里运行，外壳不花内存 |
| D55 | 阴影分三档：静置的窗口、当前窗口与今日页（抬起）、小卡片；外壳的面板用两层阴影（贴近的接触线加柔和外扩），阴影由 CSS 画 | 焦点不只靠陶土色框表达，也靠高度；niri 的图层阴影不会跟着面板动画移动（虚拟机里看到阴影先于面板出现），所以今日页也改为自己画阴影 |
| D56 | 大号衬线字用 Source Serif 4 的光学尺寸：40 px 以上用 Display，16 px 以下用 SmText，都以普通 Source Serif 4 兜底 | 同一字体按字号分别设计的版本：大字号笔画更细、更挺，小字号更扎实。实测确认字重不变（静态字体没有 Medium，原来的 500 实际就落在 Regular 上） |
| D57 | 壁纸生成时加入极淡的纸纹（`wallpaper.grain`，正文色 4%），锁屏用同一张壁纸 | 生成一次后缓存，运行时零代价；锁屏像是把同一页纸盖住，而不是换了地方。面板不加纹理，保持干净 |
| D58 | 外壳的小图标（关闭、下拉、更多）改为 cairo 自绘，线宽来自令牌 `shape.icon_stroke` | 不依赖系统图标主题，每台机器上都一样；颜色跟随 CSS，悬停变色时自动重画 |
| D59 | 外壳启动的子进程设置 `PR_SET_PDEATHSIG`，随外壳一起结束 | 只在正常退出时清理不够：外壳被杀或合成器重启时，虚拟机里残留过 3 个 `pactl subscribe` |
| D60 | 面板销毁后调用一次 `malloc_trim` | 动画每帧都会申请大块的离屏缓冲，glibc 释放后不还给系统，关闭后外壳多占约 7 MiB；加上后降到约 4 MiB，而且反复开关不再增长 |
| D61 | “关闭面板后回落到空闲的 110% 以内”改为两条：首次打开留下的缓存 ≤ 5 MiB，反复开关 10 轮增长 ≤ 1 MiB | 实测关闭后为空闲的 117%（RSS 多 4.4 MiB），**旧标准没有达到**。逐个面板测量后发现，多出来的是第一次打开时加载的字体和样式缓存，之后不再增长（10 轮只多 0.2 MiB）。原标准想抓的是泄漏，新标准抓得更准 |
| D62 | 比较外壳内存时同时看 RSS | PSS 会把共享库平摊给所有使用者：昨天测量时 gnome-text-editor 开着，和外壳分摊 GTK 4，外壳的 PSS 因此少算约 6 MiB；RSS 两天都是 51 MiB 左右 |

## 2026-11-03 下午 · 作者：要古典，不要 Windows

作者：整个设计最终要更古典，而不是更像 Windows；借鉴 Anthropic 审美，就是为了像 Claude 区别于 Gemini 的炫酷那样，区别于现有桌面的极客风。壁纸的线条画由作者挑选。

上午的一部分改动（通知从边缘滑入 24 px、今日页和搜索的大阴影）正是浮动卡片界面的做法，下午一并收回。

| 编号 | 决定 | 理由 |
| --- | --- | --- |
| D63 | 界面借用书页和印刷的语汇：版心、细线、小型大写、旧体数字、衬线正文；不用大圆角卡片、大阴影、胶囊按钮、滑入横幅 | 作者的方向。“边注”“索引”“线条插画”本来就在理念里，这次让它们在界面上真正成立 |
